«Конверт» — современный, легковесный и конфиденциальный веб-сервис для пакетной конвертации файлов между популярными форматами растровой графики, векторных контейнеров и документов PDF.

---

## 🌟 Ключевые особенности

- **25 специализированных инструментов**:
  - **Сборка PDF**: JPG → PDF, PNG → PDF, WebP → PDF, HEIC → PDF, TIFF → PDF, BMP → PDF.
  - **Извлечение из PDF**: PDF → JPG, PDF → PNG, PDF → WebP (рендеринг в высоком разрешении 200 DPI).
  - **Конвертация веб-графики**: PNG ↔ JPG, WebP ↔ JPG, WebP ↔ PNG.
  - **Apple HEIC**: декодирование фото с iPhone/iPad в JPG, PNG и сборка в PDF с автоповоротом по EXIF.
  - **Иконки Favicon (ICO)**: создание многослойных контейнеров (от 16×16 до 256×256 px) из PNG/JPG и извлечение растра.
  - **Тяжелые сканы и архивы**: TIFF ↔ JPG/PNG, BMP ↔ JPG/PNG с автоматической конвертацией профиля CMYK в sRGB.
- **Пакетная обработка**: параллельная конвертация до 40 файлов за раз с моментальной выгрузкой единым ZIP-архивом.
- **Приватность и безопасность**:
  - Файлы обрабатываются в изолированной среде и не передаются третьим лицам.
  - Все исходные и сконвертированные файлы автоматически удаляются планировщиком через 55 минут.
- **Чистый UX**: без обязательной регистрации, навязчивой рекламы и водяных знаков на документах.
- **SEO & Performance**: 
  - 100% серверный пререндеринг (SSG/SSR): весь контент доступен поисковым роботам без необходимости выполнения JavaScript.
  - Полная семантическая разметка Schema.org (`SoftwareApplication`, `FAQPage`, `BreadcrumbList`, `Organization`).
  - Адаптивный интерфейс с комфортной типографикой под мониторы высокого разрешения (HiDPI / 2K).

## 🛠 Технологический стек

### Frontend
- **Ядро**: React 19, React Router v7, Vite 8
- **Стилизация**: Tailwind CSS v4
- **Архитектура**: Собственный пайплайн статического пререндеринга (`scripts/prerender.mjs`) для мгновенной отдачи HTML.
- **Интерактивность**: Drag & Drop загрузка файлов (@dnd-kit), Web Share API для удобного шеринга ссылок.

### Backend
- **Фреймворк**: Python 3.12, Django 6, Django REST Framework
- **Очереди и асинхронность**: Celery + Redis для распределенной пакетной обработки без задержек веб-сервера.
- **Движки конвертации**: Pillow, PyMuPDF (fitz), libheif.
- **Фоновые задачи**: Celery Beat для регулярной очистки временных файлов по TTL.

### Инфраструктура
- **Веб-сервер**: Nginx (раздача статического контента, SSL/TLS, gzip, защита от перегрузок, проксирование API).
- **Контейнеризация**: Docker & Docker Compose.
- **CI/CD**: GitHub Actions (автоматическая проверка секретов, линтинг, тестирование бэкенда, сборка и верификация SEO-контрактов).

## 🚀 Локальная разработка

### 1. Запуск Backend
```bash
cd backend
# Запуск через Docker Compose (включает Django, Redis и Celery)
docker compose up -d
```
Бэкенд будет доступен по адресу `http://localhost:8000`.

### 2. Запуск Frontend
```bash
cd frontend
npm install
npm run dev
```
Фронтенд запустится на `http://localhost:5173` с автоматическим проксированием API-запросов к бэкенду.

## 🔒 Безопасность и защита данных

- **Автоматическая проверка секретов**: в репозитории настроен автоматический CI-гейт (`scripts/check_secrets.py`), который исключает попадание токенов, паролей или приватных ключей в репозиторий.
- **Изолированное хранилище**: файлы пользователей хранятся во временном томе с ограниченным сроком жизни и удаляются планировщиком через 55 минут.
- **Защита ресурсов**: валидация входных данных, ограничение размера файла (до 50 МБ) и максимального разрешения предотвращают атаки типа исчерпания памяти (DoS).
