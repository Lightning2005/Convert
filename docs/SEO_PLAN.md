## 4. Памятка разработчика по SEO-контрактам Convefy

При любых будущих правках обязательно соблюдать заложенные правила:

1. **Лимит `<meta name="description">`:**
   * Должен быть **строго ≤ 160 символов** (включая автоматическую приписку из `describeTool`). Проверяется скриптом `verify-dist.mjs`.
2. **Контракт FAQ под Schema.org:**
   * У каждого инструмента в `SUPPORTED_TOOLS` должно быть **ровно 4 вопроса** в массиве `faq`.
   * Текст вопросов и ответов в JSON-LD обязан на 100% совпадать с видимым текстом на странице.
3. **Шаги инструкции:**
   * Массив `steps` у каждого инструмента должен содержать **не менее 3 пунктов**.
4. **Никаких мягких 404:**
   * Несуществующие страницы должны возвращать реальный HTTP-статус 404 через `dist/404.html` (настроено в `nginx.conf`).
